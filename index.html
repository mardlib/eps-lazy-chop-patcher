WHAT’S INSIDE

Chop on real hardware.

  • Up to 16 chops per pass
  • Aliases share the original audio
  • Sample and loop boundaries
  • COMMAND → WAVE → LAZY CHOP
    At the end of the menu
Experimental release T11

Chopping has been confirmed on a real EPS-16 Plus and also works with the EPS-16 Plus emulator. Automatic chop naming is not working reliably yet. Undo is not included.

Disabled by this patch: COMMAND → SEQ/SONG, COMMAND → TRACK, COPY FLOPPY, COPY SCSI DRIVE and BACKUP/RESTORE.

03 — PLAY

How to

Start with a freshly recorded mono sample in a single layer. Open Lazy Chop, play the root key, then play more notes to set markers. Press YES to apply the chops, then YES again to exit. Save using the normal SAVE INSTRUMENT command.

Unofficial EPS-16 Plus extension. Not for the original EPS or ASR-10.
